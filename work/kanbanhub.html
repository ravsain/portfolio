KanbanHub: a project management platform, built end to end

Personal project · 2026

A full-stack tool that brings kanban boards, sprint tracking, real-time team chat and budgeting into one place. I scoped it, designed it and built both the Go backend and the React front end.

Role
Solo: product, design and full-stack build
Timeline

Stack

Product work & implementation

  1. Designed one workspace around the way delivery teams operate: boards, sprint tracking, chat and budgets.
  2. Built the interface in React 19 and TypeScript with Tailwind CSS and TanStack Query.
  3. Implemented a Go API with Chi and PostgreSQL via pgx, including multi-tenancy and role-based access.
  4. Added real-time team chat over WebSockets and file storage through Cloudflare R2.
  5. Integrated an AI assistant with OpenAI- and Grok-compatible APIs plus a mock fallback for demos.
One connected workspacePlanning, communication and budget visibility live alongside each other, with access controls built into the platform.

Outcome

A working full-stack platform that covers planning, team communication and budget in one product.
