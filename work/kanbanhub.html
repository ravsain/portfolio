KanbanHub: a project management platform, built end to end

Personal project · 2026

A full-stack tool that brings kanban boards, sprint tracking, real-time team chat and budgeting into one place. I scoped it, designed it and built both the Go backend and the React front end.

Role
Solo: product, design and full-stack build
Timeline
2026
Stack
Go, Chi, PostgreSQL (pgx), WebSockets, Cloudflare R2, React 19, TypeScript, Tailwind, TanStack Query

Three ways to read this project

All of them are here. The one that matches the view you picked comes first.

Product lens

matches your view
  • Scoped the product around how delivery teams work: boards, sprints, chat and budgets in one tool instead of four.
  • Multi-tenancy so separate teams or organisations can share one deployment safely.
  • Granular roles (RBAC) so each person sees and edits only what they should.
  • An AI assistant built in, with a mock fallback so the product still demos without an API key.

Engineering lens

matches your view
  • Go backend on the Chi router with PostgreSQL via pgx.
  • Role-based access control and multi-tenancy enforced in the backend.
  • Real-time chat over WebSockets; file storage on Cloudflare R2.
  • React 19, TypeScript, Tailwind CSS and TanStack Query on the front end.
  • AI assistant client compatible with OpenAI and Grok APIs, with mock fallback.

Operations lens

matches your view
  • Turns the delivery mechanics I run at work into software: kanban flow, sprint tracking and budget visibility.
  • Budgeting sits next to the board, so delivery and cost are tracked in the same place.
  • Role-based access mirrors how real teams split responsibilities.

Outcome

A working full-stack platform that covers planning, team communication and budget in one product.
