PennyWise: budgeting for people who share money

Personal project · 2026 · live

A budgeting app for web and mobile built around a Netflix-style shared account: several people live under one primary account and see the same numbers in real time.

Role
Solo: product and full-stack build
Timeline
2026
Stack
React, React Native, Python API, Supabase (PostgreSQL), JWT, RBAC

Three ways to read this project

All of them are here. The one that matches the view you picked comes first.

Product lens

matches your view
  • Designed the shared account model: one primary account with several members, like a family streaming plan.
  • Real-time sync so every member sees the same balance at the same time.
  • Built for web and mobile, so people can budget wherever they are.

Engineering lens

matches your view
  • React web app and React Native mobile app sharing one Python API.
  • Supabase (PostgreSQL) with row-level security policies protecting each account's data.
  • JWT authentication and role-based access control for multi-user accounts.
  • Documented API with interactive docs.

Operations lens

matches your view
  • Shipped and running: web on Vercel, API on Render, data on Supabase.
  • Access is checked in the API and again in the database through row-level security.
