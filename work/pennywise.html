PennyWise: budgeting for people who share money

Personal project · 2026 · live

A budgeting app for web and mobile built around a Netflix-style shared account: several people live under one primary account and see the same numbers in real time.

Role
Solo: product and full-stack build
Timeline
2026
Stack
React, React Native, Python API, Supabase (PostgreSQL), JWT, RBAC

Web is hosted on Vercel, the API on Render, and data on Supabase.

Product work & implementation

  1. Designed a shared-account model so several members can manage and track a common budget in real time.
  2. Built React web and React Native apps on a shared Python API.
  3. Used Supabase PostgreSQL with row-level security to protect account data.
  4. Added JWT authentication, role-based access and documented interactive API endpoints.
  5. Deployed the web app to Vercel, the API to Render and data on Supabase.
Shared by designOne account model keeps balances in sync across members, with access enforced in both the API and database.

Outcome

Live and usable today, on web and mobile.
