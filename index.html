How I work

The whole loop, not one slice of it.

Most roles cover one or two of these stages. I've done all six, which is why requirements, code, tests and delivery don't fall apart between teams.

  1. Discover

    Talk to clients and stakeholders to find the real problem behind the request.

    StakeholdersRequirements

  2. Define

    Turn it into PRDs, specs and a prioritised backlog the team can start on.

    PRDsBacklog

  3. Build

    Write the code: Go services, Python agents, React front ends.

    GoPythonReact

  4. Test

    Automate the checks so every release is safer than the last.

    PlaywrightSelenium

  5. Ship

    Run delivery with Scrumban and coordinate the rollout across teams.

    ScrumbanJira

  6. Measure

    Read the data with SQL and dashboards, then feed what I learn into the next cycle.

    SQLDashboards
